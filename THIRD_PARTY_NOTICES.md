# Third-party boundaries

This draft uses separately installed Python dependencies listed in `requirements.txt`. Their source, licenses, and notices remain their own; the proposed project license does not replace those terms. Review the exact resolved dependency versions and their license files when preparing a distributable release. No dependency source or model weights are intentionally vendored in this repository.

The optional OCR command uses a separately installed Tesseract executable and English language data. Neither the executable nor its trained data is bundled here; their licenses and attribution remain separate from this draft. The optional browser test likewise uses separately installed Playwright and a browser.

iBlueprint, WAERlinx, NetSuite, Ollama, Mozilla, and Harvest Hope names identify the relevant project context or compatible/proposed mechanisms. Their mention does not imply endorsement, partnership authorization, or a license to redistribute their proprietary materials.

The original project notes, inventory manual, meeting transcripts, and operational data are not distributed here. Private iBlueprint workflow URLs and identifiers are omitted; no proprietary workflow implementation or execution API is distributed.

If a local model is added, preserve the license and attribution required for its exact weights and record its origin in a completed model card. “Open weights” is not a substitute for checking those terms.
